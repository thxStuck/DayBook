Экспорт событий

Меню «Экспорт» на панели инструментов. Экспортируется текущий результат: запрос, фильтры, временное окно, а если выбрана группа — только она. Порядок строк — как на экране. После экспорта файл показывается в Finder.

ФорматОсобенности
CSVЗапятая, UTF-8 без BOM, строки через CRLF, кавычки по RFC 4180. Значения не меняются
CSV для Excel (;)Точка с запятой и BOM. Значения, начинающиеся с =, +, -, @, табуляции или CR, получают впереди апостроф, чтобы Excel не выполнил их как формулы
JSON LinesОдно событие — одна строка JSON. Поле source_file — полный путь. Повторяющиеся поля в data записываются массивом
Excel (XLSX)Лист «События» с закреплённым заголовком и автофильтром; лист «Сведения» с параметрами экспорта

Колонки

КолонкаСодержимое
Time (<пояс>)Время в выбранном часовом поясе, до миллисекунд
TimeUTCВремя в UTC, 7 знаков после запятой и Z
Computer, Channel, Provider, EventIDСистемные поля
LevelУровень числом
UserSID, RecordIDSID пользователя из System и номер записи
SourceFile, SourceSHA256Имя исходного файла и его SHA-256
FlagsФлаги записи
Ваши колонкиПоля, которые вы добавили в таблицу
EventDataВсе поля события в виде «имя: значение | …»

Особенности XLSX

  • EventID, Level и RecordID записываются числами, всё остальное — текстом, никогда не формулами.
  • Не больше 1 048 575 строк (предел Excel). Если результат больше, приложение предложит сузить запрос.
  • Ячейки длиннее 32 767 символов обрезаются и заканчиваются пометкой «…[обрезано: полная длина N символов]»; их число указано на листе «Сведения».
  • Лист «Сведения»: путь кейса, время экспорта (UTC), часовой пояс, запрос, фильтры, временное окно, порядок строк, число событий, исходные файлы с SHA-256 и числом записей.

Примечание

Описание события (колонка «Описание / данные события» в таблице) формируется при показе и в экспорт не попадает. Все данные события есть в колонке EventData.

Экспорт детектов

На экране «Детекты» сработавшие правила выгружаются в CSV — обычный или для Excel (с той же защитой от формул). Колонки: Level, Rule, Events, Hosts, первое и последнее срабатывание в выбранном поясе и в UTC, Author, RuleSet (SigmaHQ, Hayabusa или своя папка), RulePath, RuleID, Status, Tags (в том числе техники MITRE ATT&CK), References, License и DQL — запрос, в который переведено правило.

Утилита командной строки evtxdump

Собирается вместе с приложением скриптом scripts/build.sh: Packages/DaybookKit/.build/release/evtxdump. Использует то же ядро, что и приложение.

КомандаСинтаксисНазначение
ingest<case.daybook> <файлы/папки>… [--no-merge] [--no-carve] [--no-hash]Создать кейс. Папка кейса не должна существовать. Детекты не запускаются
dql<case> "<запрос>"Выполнить запрос DQL. Время выводится в UTC
query<case> [key=value \| key!=value]… [--facet key]Фильтры как в интерфейсе: первые строки результата и замеры времени
entities<case> [--rebuild]Показать или пересобрать реестр хостов, пользователей и IP
sessions<case>Сеансы входа и RDP
processes<case>Деревья процессов
sigma<case> --pack rules.json [--dir папка] [--rule id\|путь] [--compile-only] [--verify] [--top N]Выполнить правила Sigma. Результаты записываются в кейс
export<case> <out.csv\|out.jsonl\|out.xlsx> ["DQL"] [--fields a,b]Экспорт; формат определяется по расширению
stats<файлы/папки>…Состояние файлов и чанков без создания кейса
carve<файлы/папки>…Статистика восстановления из slack
xml<файл> [--limit N] [--jsonl]XML живых записей файла
json<файл> [--limit N]Записи файла, по одной строке JSON

Примеры

evtxdump ingest case.daybook /path/to/winevt/logs
evtxdump dql case.daybook 'EventID = 4625 | group by IpAddress'
evtxdump sigma case.daybook --pack DayBookEvtxMacOS/Resources/Rules/rules.json --top 20
evtxdump export case.daybook out.xlsx 'EventID = 4688'
evtxdump stats /path/to/logs

Отличия от приложения

  • export из командной строки не умеет «CSV для Excel» и выводит время только в UTC.
  • В dql время в запросе понимается в UTC и только в формате ГГГГ-ММ-ДД[ ЧЧ:ММ[:СС]]: без долей секунды, суффикса Z и смещений.
  • В export условия по времени в запросе не поддерживаются — запрос с ними вернёт ошибку. Используйте dql, чтобы найти нужное, или экспортируйте из приложения.
  • sigma --verify дополнительно проверяет каждое срабатывание независимым упрощённым вычислителем и сообщает о расхождениях — это проверка самого движка.
