## Требования

- macOS 14 или новее.
- Mac на Apple Silicon. Сборка под Intel не проверялась.
- Для сборки из исходников — Xcode с Swift 6. Проверялось на Xcode 27 и macOS 26.

## Установка готовой сборки

1. Откройте [последний релиз](https://github.com/thxStuck/DayBook/releases/latest) и скачайте
   архив `DayBookEvtxMacOS-<версия>-arm64.zip`.
2. Распакуйте архив и перенесите `DayBookEvtxMacOS.app` в «Программы».
3. Если хотите проверить архив, сравните его SHA-256 со значением в описании релиза:

   ```bash
   shasum -a 256 ~/Downloads/DayBookEvtxMacOS-*-arm64.zip
   ```

### Первый запуск

Приложение подписано локально (ad-hoc) и не нотаризовано Apple: для нотаризации нужен платный
Developer ID. Поэтому при первом запуске macOS откажется его открывать.

1. Закройте окно с предупреждением.
2. Откройте «Системные настройки» → «Конфиденциальность и безопасность».
3. Внизу, рядом с сообщением о DayBookEvtxMacOS, нажмите «Всё равно открыть» и введите пароль
   администратора.

То же самое можно сделать в Терминале — команда снимает с приложения отметку «скачано из интернета»:

```bash
xattr -dr com.apple.quarantine /Applications/DayBookEvtxMacOS.app
```

### Доступ к папкам

Песочница у приложения выключена: утилите для расследований нужно читать файлы в любых местах.
Но папки «Документы», «Рабочий стол», «Загрузки», внешние и сетевые диски macOS всё равно защищает
отдельно. Когда приложение впервые обращается к такой папке, система спрашивает разрешение.

- Разрешите доступ — иначе приложение не сможет прочитать журналы при импорте и вкладки
  XML и Hex в деталях события.
- Если доступ был запрещён, включите его в «Системные настройки» → «Конфиденциальность и
  безопасность» → «Файлы и папки» → DayBookEvtxMacOS.
- Каждая новая сборка с локальной подписью для macOS — новое приложение, поэтому после обновления
  запрос может появиться снова.

## Язык интерфейса

Интерфейс есть на русском и английском. По умолчанию язык выбирается по системе:
если первым в списке языков macOS стоит русский — интерфейс русский, иначе английский.

Сменить язык в самом приложении: меню **DayBookEvtxMacOS → Язык интерфейса** → «Как в системе»,
«Русский» или English. Язык применяется при запуске, поэтому приложение предложит перезапуститься;
открытый кейс откроется снова.

Это та же настройка, что «Системные настройки» → «Основные» → «Язык и регион» → «Приложения».
Её можно задать и в Терминале:

```bash
defaults write app.daybook.evtx AppleLanguages -array en
```

Вернуть язык системы:

```bash
defaults delete app.daybook.evtx AppleLanguages
```

## Справка и сведения о программе

- **«Справка» → «Справка DayBookEvtxMacOS»** (⌘?) открывает эту документацию в системном окне
  справки — без интернета. Поле поиска в меню «Справка» ищет и по ней.
- В том же меню — документация на сайте, справочник DQL на сайте, «Сообщить об ошибке…» и страница
  проекта на GitHub.
- **DayBookEvtxMacOS → О программе DayBookEvtxMacOS** — версия, ссылки и сторонние компоненты
  с их лицензиями.

## Сборка из исходников

```bash
git clone https://github.com/thxStuck/DayBook.git
cd DayBook
scripts/build.sh
open build/DayBookEvtxMacOS.app
```

Скрипт собирает:

- приложение в режиме Release — `build/DayBookEvtxMacOS.app`;
- утилиту командной строки — `Packages/DaybookKit/.build/release/evtxdump`
  (см. [Экспорт и командная строка](export-cli.html)).

Если `xcode-select` указывает на Command Line Tools, скрипт сам использует
`DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`. Можно также открыть
`DayBookEvtxMacOS.xcodeproj` в Xcode и нажать ⌘R.

Единственная внешняя зависимость — библиотека [Yams](https://github.com/jpsim/Yams) (MIT) для чтения
YAML правил Sigma. Swift Package Manager скачивает её при первой сборке.

## Где что хранится

| Что | Где |
|---|---|
| Кейс | Папка `<имя>.daybook` там, где вы её создали при импорте |
| Исходные журналы | Остаются на месте; в кейсе хранятся абсолютные пути к ним |
| Настройки приложения | Домен `app.daybook.evtx` (`defaults read app.daybook.evtx`) |
| Встроенные правила Sigma | Внутри приложения: `Contents/Resources/rules.json` |
